# Equipe 7

Projeto desenvolvido para o desafio final da disciplina de Integração de Dados.

## Objetivo

Monitorar a qualidade do ar e os atendimentos respiratórios em diferentes regiões, integrando dados de fontes externas e internas para apoiar a análise e a tomada de decisão.

## Problema

A qualidade do ar pode impactar diretamente a saúde da população. Este projeto busca identificar regiões com maior risco respiratório e apresentar indicadores claros em um painel visual.

## Tecnologias

- Python
- FastAPI
- React
- SQLite
- DuckDB
- MongoDB
- Apache Hop
- API Open-Meteo

## Funcionalidades

- Dashboard com indicadores de saúde e qualidade do ar
- Alertas por região
- Tendência de atendimentos respiratórios
- Busca por território
- Integração de dados externos e consolidação em bancos locais

## Execução

1. Clone o repositório
2. Acesse a pasta do projeto
3. Execute os serviços com Docker ou o ambiente local configurado
4. Inicie o backend Python
5. Inicie o frontend React
6. Acesse a aplicação no navegador

## Estrutura

- backend/: API e processamento dos dados
- src/: frontend em React
- integrations/: arquivos e workflows de integração
- data/: arquivos de dados e bancos locais

## Observação

A solução combina múltiplas fontes de dados para demonstrar o uso de integração, armazenamento e visualização em um contexto real e aplicado.
